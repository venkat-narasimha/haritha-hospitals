# Prompts — AI Generator Templates

Reusable prompt templates for generating artifacts (presentations, docs, code) from this project.

## Index

- `shift-management-cmm-l5-presentation.md` — v2.1 — Generates a 17-slide self-contained HTML presentation on shift management. Used to produce `docs/handbook/03-client/shift-management-presentation-v1.html` and `-v2.html`.

## How to use

1. Open the prompt in your AI assistant (Claude, GPT, etc.)
2. Copy the prompt text
3. Paste into the assistant as input
4. The assistant will generate the artifact per the spec
5. Save output to the appropriate location

## Regeneration policy

When prompts change, bump the version (v1 → v2 → v3) at the top of the file.
