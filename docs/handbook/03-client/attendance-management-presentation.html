Auto Attendance (the conversion engine)

Auto Attendance is a background process that converts raw Employee Checkin rows into Attendance rows by matching punch times against Shift Type configurations and Holiday List dates.

  • Cron-driven — runs on a scheduled interval.
  • Matches against Shift Type + Holiday List.
  • Respects grace period + late/early thresholds.
Auto Attendance is a scheduled background process. It reads checkins, matches against the employee's Shift Type grace window and Holiday List, and writes Attendance rows. The match engine handles late arrivals, early departures, and missing punches.

Transition: "Not all attendance comes from punches — sometimes HR needs to mark it manually."

Employee Attendance Tool (bulk marking)

The Employee Attendance Tool lets HR Admins bulk-mark attendance for a date range. Useful for non-biometric sites, off-team events, or catching up on missed entries.

  • Bulk mark by department / grade.
  • Exclude holidays toggle.
  • Apply status (Present / Absent / Half Day) in bulk.
The Attendance Tool is the HR escape hatch when Auto Attendance can't infer status correctly. Use it for non-biometric sites, off-site events, or catch-up entries.

Attendance Request (employee regularisation)

An Attendance Request lets an employee regularise a missed check-in or dispute a recorded absence. Approval routes to the employee's leave approver.

  • Self-service form (employee submits).
  • Reason text + supporting attachment.
  • Approver workflow (routes to leave approver).
