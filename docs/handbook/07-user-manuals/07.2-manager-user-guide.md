## Welcome, HR Manager

You are the operational hub for your department or HR function. The HRMS gives you the tools to:

- See your team's roster at a glance
- Approve leave, attendance corrections, shift swaps
- Track headcount, attendance %, leave liability
- Process monthly payroll with sign-off
- Stay compliant (PF, ESI, professional tax, audits)

**Core principle:** *approve fast, document everything*. Every approval is an audit trail entry. Every rejection needs a reason.

## Your dashboard

When you log in, the **Home** dashboard shows manager-relevant widgets:

- **Pending Approvals** — count of Leave Applications + Attendance Requests awaiting your action
- **Team on Shift Today** — headcount by department
- **Today's Absentees** — flagged before 10:00 IST (auto-generated from missing check-ins)
- **This Month's Payroll Status** — Draft / Submitted / Approved
- **Compliance Due** — PF ECR generation, ESI return, professional tax filing deadlines
- **Recent Activity** — last 10 actions by your team

Click any widget to drill down. The **Pending Approvals** widget is your daily starting point.

## Team management

### Viewing your team

Two ways to see the people who report to you:

1. **Employee list (filtered)**:
   - Human Resources → Employee → filter `Department = <your department>`
   - Add column `Reports to = <you>` for direct reports only
2. **Department tree view**:
   - Human Resources → Department → open your department
   - Tab **Employees** shows everyone, with reporting hierarchy

### Team member profiles

Click any employee name to open their full record. Useful tabs:

- **Personal** — name, contact, emergency contact
- **Employment** — department, designation, date of joining, employment type
- **Salary** — salary structure, base, current gross (HR/payroll only)
- **Leave** — current balances, history
- **Attendance** — last 30 days summary
- **Shift Assignment** — current roster block

> **Permission note:** You see salary for your direct reports only. Aggregate department salary is visible; individual non-report salary is not.

### Onboarding a new employee (manual checklist)

The system has no wizard — you follow this checklist:

1. **HR creates the Employee record** (Human Resources → Employee → New):
   - First/Last Name, Gender, DOB
   - Date of Joining, Department, Designation
   - Employment Type (Full-time / Part-time / Contract / Intern)
   - Holiday List assignment
   - Reports To = manager name
2. **IT creates the User account** (Settings → User → New):
   - Email (company standard)
   - Role: Employee + Department-specific role
   - Send invite (system emails temp password)
3. **Payroll sets the Salary Structure** (assign a structure template).
4. **You set the Shift Assignment** (first 30 days default = day shift).
5. **Add to relevant rosters** — `/hr/roster` reflects shift assignments.
6. **Issue laptop / ID card / biometric enrollment** — IT handles.

> **Time to onboard:** ~30 min if all data is ready. Most delays are from missing docs (Aadhaar, PAN, photo).

### Offboarding (exit process, deactivate user)

When an employee resigns / is terminated:

1. **Mark Relieving Date** in Employee record → Status becomes "Inactive" on that date.
2. **Clear leave balance** — leave encashment decision (HR/payroll).
3. **Run Full & Final Settlement** — payroll team. Last payslip includes F&F.
4. **Revoke user** — Settings → User → set **Enabled = 0** (don't delete, archive).
5. **Remove from shift assignments** — system auto-excludes inactive employees from roster.
6. **Hand-over** — return laptop, ID card, biometric data deletion request.
7. **Update audit log** — IT logs the offboarding with date + reason.

> **Don't delete the Employee record.** Inactive flag preserves historical reports (attendance, payslips). Deletion breaks reports and audit.

## Roster management

### Viewing team roster

1. Go to `https://pberpprod.duckdns.org/hr/roster`.
2. Filter: **Department = <your department>**, **Date Range = next 2 weeks** (typical planning horizon).
3. Color-coded cells show shift per person per day.

### Bulk shift assignment (Shift Assignment DocType)

For assigning next month's roster to the whole team:

1. Human Resources → Shift Assignment → New.
2. Fill:
   - **Company** = Haritha Hospitals
   - **Shift Type** = e.g. `G0900R0900` (General 09–18)
3. In the **Employees** child table, add rows for each team member:
   - **Employee** = name
   - **Start Date**, **End Date** = the assignment window (e.g. 1 Sep – 30 Sep)
4. Save → Submit.

> **Bulk import tip:** Use the "Add Multiple" button on the child table. Type 5–10 employee names quickly. Faster than CSV import for small teams.

### Reassigning shifts

Three scenarios:

1. **Last-minute swap (same day)** — open the original Shift Assignment, click **Cancel**, create new ones. Or use **Shift Request** DocType if your team uses it.
2. **Future change** — open the future Shift Assignment, edit the date/shift, save.
3. **Bulk change** — create new Shift Assignments for the date range, old ones cancel automatically (via overlap validation).

### Handling shift swap requests

Employees request swaps via **Shift Request** (Human Resources → Shift Request):

1. View pending requests → click each.
2. See who wants to swap with whom, which dates, which shifts.
3. **Approve** if both are competent for the shift (especially clinical roles).
4. The system creates corresponding Shift Assignments.

> **Red flag:** Frequent swap requests from the same employee may indicate roster dissatisfaction — talk to them.

### Holiday impact on shifts

When a holiday falls on a scheduled shift:

- Employees who work that day earn **Comp-Off** (1 per holiday shift).
- HR or payroll credits Comp-Off automatically via **Leave Ledger Entry** (system-side).
- You see it in the employee's Comp-Off balance within 24 hours.

> Verify monthly: run **Leave Ledger Entry** report filtered by leave type = "Compensatory Off" — it should match your manual holiday roster.

## Attendance management

### Viewing team attendance

1. Human Resources → Attendance → filter `Department = <X>`, `Attendance Date = today`.
2. List view shows each employee's check-in, check-out, working hours, status.

Or for a trend:

1. Human Resources → Attendance → Report → **Attendance Summary** (date range, department).
2. Exports to Excel.

### Approving attendance corrections

Employees file **Attendance Request** when check-in fails:

1. Home → **Pending Approvals** widget → click Attendance Request.
2. Each row shows: employee, date, requested status, reason.
3. **Approve** if reason is valid (network outage, biometric failure, forgot phone).
4. **Reject** with a reason if the pattern looks suspicious (daily requests from same person).

> **Rule of thumb:** Approve if employee has <2 requests in 30 days. Escalate to HR if >3.

### Marking manual attendance (when checkin missed)

When you know an employee worked but no check-in exists:

1. Human Resources → Attendance → New.
2. Fill: employee, date, status = Present, working hours (estimate), remark = "Manual: <reason>".
3. Save → Submit.

> **Limit:** You can mark up to 7 days back. Beyond that, payroll team must do it (with HR approval).

### Auto Attendance review

The system auto-creates Attendance from Employee Checkin records:

1. Verify it ran: `bench --site pberpprod console` → check `last_sync_of_checkin` on Shift Type.
2. Review mismatches: Human Resources → Auto Attendance → filter by today.
3. Manually fix any "Skipped" entries (usually due to holiday / leave overlap).

> See [02.1 Shift Management Workflow](../02-workflow/02.1-shift-management-workflow.md) for the full auto-attendance logic.

## Leave management

### Approving / rejecting leave applications

1. Home → Pending Approvals → Leave Application.
2. Each row: employee, leave type, dates, days, reason.
3. **Before approving, check:**
   - Leave balance is sufficient
   - No overlap with approved leave for same dates
   - Adequate coverage (other team members not all on leave)
   - Critical dates (month-end, audit week, surgery block)
4. **Approve** or **Reject** (rejection needs a reason — recorded in audit log).

> **Tie-break:** If two people request the same dates, approve the one who applied first. If equal timestamp, ask them to resolve.

### Leave calendar view (team-wide)

1. Human Resources → Leave Application → Calendar (top-right toggle).
2. Color = leave type. Click any entry to see details.

Useful for spotting coverage gaps.

### Leave balance tracking

1. Human Resources → Leave Type → open a type → tab **Ledger**.
2. Shows every employee's accrual, usage, balance.
3. Or per-employee: Employee record → Leave tab.

### Carry forward rules

Configurable per Leave Type. India defaults:

| Leave Type | Carry Forward Rule |
|---|---|
| Casual Leave | **None** — lapses 31 Mar |
| Sick Leave | **None** — lapses 31 Mar |
| Earned Leave | **Up to 30 days** carry forward |
| Comp-Off | **Up to 30 days** carry forward |

> **Verify yearly:** Run **Leave Ledger Entry** report on 1 April — EL balances should reset to "carried forward" portion. If not, escalate.

## Payroll oversight

### Reviewing salary slips before processing

Before payroll run (typically 28th–30th of each month):

1. Human Resources → Salary Slip → filter `Company = Haritha Hospitals`, `Month = <current>`.
2. Open each slip, verify:
   - **Working days** matches actual attendance + paid leave
   - **Loss of pay** = unpaid leave days × (gross / 30)
   - **PF** = 12% of Basic
   - **ESI** = 0.75% of Gross (if applicable)
   - **PT** = state rate (₹200 for Karnataka, ₹0 if income < threshold)
   - **TDS** matches projected monthly tax

3. **Flag anomalies** — wrong Basic, missing deduction, double-credit — to payroll team.
4. Payroll team runs **Process Payroll** after your sign-off.

### Salary Structure management

Each employee has a Salary Structure assigned:

1. Human Resources → Salary Structure → New (or edit existing).
2. Components: Basic, HRA, Allowances (list), Deductions (list).
3. **Approve** → assigns to employee.

> **Frequency:** Annual review (April). Off-cycle changes need HR + MD approval.

### Reporting payroll anomalies

Common issues:

- Wrong basic → check Salary Structure assignment
- Missing PF → check employee has PF applicable flag
- Excess TDS → check investment declarations (Form 12BB)
- Wrong net pay → recompute from components

Always escalate to payroll team via the Payroll Issue Tracker (separate spreadsheet) — do not edit payslips directly.

`/app/hr` (or Human Resources → HR Analytics):

## Compliance

### Statutory reports (India-specific)

| Report | Frequency | Where |
|---|---|---|
| **PF ECR** (Employee Contribution Report) | Monthly | `bench --site X execute erpnext.regional.india.setup.generate_pf_ecr` |
| **ESI Contribution** | Monthly (twice-yearly return) | Payroll → ESI Report |
| **Professional Tax** | Monthly (state-specific) | Payroll → PT Report |
| **Form 24Q (TDS)** | Quarterly | Payroll → TDS → Form 24Q |
| **Form 16 (TDS Certificate)** | Annual (after year-end) | Payroll → TDS → Form 16 |

> **Deadlines:** PF by 15th, ESI by 15th, PT by end-of-month. Mark in your calendar.

### Audit trail

Every create / edit / submit / cancel of a HR record logs:

- **Who** did it
- **When** (timestamp)
- **What** changed (diff view)
- **IP address**

Access via: Human Resources → <DocType> → open record → **Audit Trail** (top-right dropdown).

> **Retention:** 8 years minimum (India compliance). Don't archive earlier than that.
