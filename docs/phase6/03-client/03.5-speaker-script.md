## Slide 6: Shift Types & Color Coding

**Duration:** ~3 minutes
**Opening:** "Twenty-five shift types, but organized by a simple prefix convention: G for General, M for Morning, A for Afternoon, N for Night. Each gets a color, and the colors carry through the entire UI."
**Key points:**
- G (General) = blue, M (Morning) = green, A (Afternoon) = orange, N (Night) = violet
- Naming: \`[Type][StartHHMM][R/S][EndHHMMh]\` — e.g., \`G0900R0830\` = General 09:00, Regular 8.5h
- 25 specific shift types = 4 base patterns × variants
- 24/7 coverage with the four color-coded patterns
**Demo moment:** n/a — visual only
**Anticipated Q&A:**
- Q: "Can we add new shift types?" → A: "Yes — from the UI, no code needed."
- Q: "Why a naming convention?" → A: "Lets supervisors read rosters at a glance; matches HRMS-native flag format."
