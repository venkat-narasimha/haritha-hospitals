## Governance — sign-off checklist

- [ ] **Steering committee formed** with named members from client + partner (chair: Client Project Lead)
- [ ] **Weekly cadence agreed** — recurring slot (e.g., Tuesday 10:00–11:00 IST), standing agenda
- [ ] **Standing agenda** documented: status by phase, blockers, change requests, risk register, next-week commitments
- [ ] **Escalation matrix** documented with 3–4 layers (e.g., Operational → Project Lead → Steering Committee → Sponsor)
- [ ] **Communication plan** signed — channels (email/WhatsApp/Teams), response SLAs, decision authority
- [ ] **Risk register** started with top 5 risks; owners assigned
- [ ] **Change-request process** agreed — written CR, impact estimate, sign-off before implementation
- [ ] **Issue log** channel agreed (e.g., GitHub Issues on `haritha-hospitals` repo)

## Weekly stand-up agenda template

1. **Roll-call** (2 min) — attendees
2. **Last-week recap** (5 min) — what was completed vs plan
3. **Phase status** (10 min) — RAG (red/amber/green) per active phase
4. **Blockers** (10 min) — anything blocking progress; escalation needed
5. **Change requests** (10 min) — new CRs to evaluate; impact estimates
6. **Risk register** (5 min) — new risks; mitigation updates
7. **Next-week commitments** (5 min) — who owes what by when
8. **AOB** (3 min) — any other business
