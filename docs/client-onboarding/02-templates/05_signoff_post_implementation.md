## Hypercare closure — sign-off checklist

- [ ] **Hypercare period completed** (typically 2–4 weeks post-go-live) with daily/weekly cadence per Phase 6 plan
- [ ] **Hypercare incident log reviewed** — all P1/P2 incidents resolved; closure summary attached
- [ ] **Satisfaction survey completed** by client stakeholders (target: ≥4/5 average; any <3 escalated)
- [ ] **Outstanding issues logged** in backlog with priority, owner, and target resolution date
- [ ] **Ongoing support plan agreed** — e.g., monthly retainer (X hours), quarterly check-in, on-demand per-hour
- [ ] **Knowledge transfer completed** — client IT team can perform basic admin (user creation, password reset, basic reports)
- [ ] **Documentation handover** — runbooks, user guides, admin guide, troubleshooting playbook all delivered
- [ ] **Custom Development Tracker** closed — all custom code deployed, tracked, and owned by client IT or partner
- [ ] **Final project retrospective** conducted; lessons-learned documented
- [ ] **Contract closure** — final invoice, any change-request true-ups, project formally closed in both organisations' systems
