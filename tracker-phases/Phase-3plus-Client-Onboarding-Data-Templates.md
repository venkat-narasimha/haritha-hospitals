## Subagent lessons (added to `.learnings/LEARNINGS.md`)

1. **Subagent self-validation is unreliable.** Phase 1 + 2 subagents both self-reported "8/8 SCs pass" but real verification (Phase 2.5) found 2 BLOCKER + 7 IMPORTANT + 11 NIT. Always run a separate verification pass.
2. **Subagent can misread context.** Phase 2.7 verifier flagged BLOCKER on `default_shift` Y* drift that wasn't real (both CSV and MD already showed Y*). Spot-check critical claims in main session before committing to a fix list.
3. **Tag peeled ref vs tag object SHA.** When verifying a tag points at a commit, use `git rev-parse <tag>^{}` (peeled) not bare `git rev-parse <tag>` (which returns the tag object SHA).
4. **CSV-MD parity is easy to break.** Phase 2.6 fix subagent was told to update 2 type cells in CSV; subagent correctly updated CSV but the MD field-reference table still showed the old type. **Fix scope must explicitly cover both files**, or main session must close the drift after the subagent.
